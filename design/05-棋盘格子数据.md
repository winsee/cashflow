## 1. 老鼠赛跑内圈（24 格序列）

自"开始"箭头起顺时针。结构与官方一致：机会×12、银行结算日×3、市场风云×3、额外支出×3、慈善×1、孩子×1、失业×1。

```
机会 → 额外支出 → 机会 → 慈善事业 → 机会 → 银行结算日 →
市场风云 → 机会 → 额外支出 → 机会 → 孩子 → 机会 →
银行结算日 → 机会 → 市场风云 → 机会 → 额外支出 → 机会 →
失业 → 机会 → 银行结算日 → 机会 → 市场风云 → 机会 → (回到开始)
```

⚠️ 右列（照片中倒置）个别相邻格的先后顺序建议在模式二开工前对实物再核对一次；模式一不依赖此序列。

## 5. 入库方式

本表数据落地为 `server/data/board/fast_track.json` 与 `rat_race.json`（结构化 JSON，人工可直接修正/补充，权威数据源，见 design/04 §2.5），启动时与卡牌一同导入 SQLite 缓存（deck = FASTTRACK_BUSINESS / FASTTRACK_DREAM / FASTTRACK_SPECIAL），复用 Effect DSL：
- 绿格 → `{op:"FT_BUY_BUSINESS", data:{cashflow|diceRule, downPayment}}`
- 掷骰绿格 diceRule = `{threshold, successCashflow}` 或一次性 `{threshold, lumpSum:500000}`
- 粉格 → `{op:"FT_BUY_DREAM", data:{price}}`
- 特殊格 → 对应引擎内建动作（无需数据）。
模式一 UI：玩家停格后在"快车道行动"面板按名称选格（列表短，无需拍照识别）。
