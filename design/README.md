## 关键设计决策速览

1. **识别 = 封闭集匹配，不做字段解析**：数值全部来自预录卡牌库，OCR 只定位"是哪张卡"，手动选卡永远兜底。
2. **服务器权威 + 事件溯源**：账目由服务端规则引擎（纯函数）计算，事件日志支持恢复/审计/房主改账。
3. **建议取消实体现金与纸质记录卡**（App 即银行+记录卡），避免双轨脱节；可配置保留。
4. **轻量回合指针**（点"结束回合"）支撑慈善 3 轮 / 停赛 2–3 轮 / 机会失效等回合类规则。
5. **里程碑顺序**：M1 先做"无 OCR 可完整玩一局"，OCR 在 M3 才接入。
