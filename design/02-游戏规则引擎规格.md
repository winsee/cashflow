# 游戏规则引擎规格（老鼠赛跑 + 快车道）

> 版本 v0.1 · 2026-07-18
> 本文档是规则的**权威数字化规格**：所有公式、状态机、边界条件均以此为准实现与测试。
> 依据说明书（docs/现金流游戏说明书.pdf）整理；条目后标注页码（P.n）便于对照原文核查。
> 标注 ⚠️ADAPT 的条目是数字化适配决策（与纸面玩法有出入），需用户知悉。

## 1. 术语

| 术语 | 定义 |
|---|---|
| 老鼠赛跑 | 内环阶段，目标：非工资收入 > 总支出（P.1） |
| 快车道 | 外环阶段，目标：买到梦想 或 现金流量日收入 +$50,000（P.1、P.5） |
| 非工资收入 | 利息 + 股利 + Σ房地产现金流 + Σ企业现金流（记录卡） |
| 总收入 | 工资 + 非工资收入 |
| 总支出 | 见 §3 支出公式 |
| 月现金流 | 总收入 − 总支出，银行结算日的收付额 |
| 现金流量日收入 | 快车道阶段每经过"现金流量日"格的收入 |

## 2. 全局状态机

```
房间: LOBBY → SETUP(选职业/排顺序/发钱) → PLAYING → FINISHED
玩家: phase ∈ { RAT_RACE, FAST_TRACK, OUT(破产出局) }
玩家回合状态: skipTurns(0..3), charity(剩余轮数 0..3 | 快车道为永久), inTurn(bool)
```

- 回合顺序在 SETUP 排定后**全局不变**，从老鼠赛跑带入快车道（P.2 开始游戏.3）。
- 多名玩家可同时处于不同 phase（有人已进快车道，有人还在内环）。
- 同格互不影响（P.2 开始游戏.4 注）。

## 3. 财务模型（老鼠赛跑）

### 3.1 记录卡结构（电子化后的字段）

**损益表**
- 收入：工资 salary；利息 interestIncome；股利 dividends（来自持股：Σ 股数×每股红利）；房地产收入行 [{资产id, 月现金流}]；企业收入行 [{资产id, 月现金流}]。
- 支出：税金、住房抵押贷款支出、教育贷款支出、购车贷款支出、信用卡支出、额外支出（职业卡固定值）、其他支出、孩子支出、银行贷款支出、**卡牌新增周期支出行**（如游艇月供 $340，动态列表）。

**资产负债表**
- 资产：银行储蓄（仅开局用，发钱后清零）；证券 [{代码, 股数, 每股成本}]；房地产 [{类型, 首期支付, 总成本}]；企业 [{名称, 首期支付, 总成本}]。
- 负债：住房抵押贷款、教育贷款、购车贷款、信用卡、额外负债、房地产抵押贷款 [{资产id, 金额}]、企业负债 [{资产id, 金额}]、**卡牌新增负债行**（如游艇贷款 $17,000）、银行贷款。

**其他**：现金 cash；孩子数 childCount（0–3）；每孩支出 perChildExpense（职业卡定值）。

### 3.2 派生公式（服务器每次变更后重算，客户端只显示）

```
股利收入      = Σ(持仓股数 × 该股每股月红利)          // 多数股票红利为0
非工资收入    = 利息 + 股利收入 + Σ房地产现金流 + Σ企业现金流
总收入        = 工资 + 非工资收入
孩子支出      = 每孩支出 × 孩子数
银行贷款支出  = 银行贷款余额 × 10%                    // P.4：每借$1,000月息$100
总支出        = 税金 + 住房抵押 + 教育 + 购车 + 信用卡 + 额外支出(固定)
              + 其他支出 + 孩子支出 + 银行贷款支出 + Σ卡牌周期支出
月现金流      = 总收入 − 总支出
进入快车道条件 = 非工资收入 > 总支出                   // P.3、P.5
```

**校验（回归用例，来自说明书）**：
- 医生（P.7）：工资13,200；支出 3,420/1,900/750/380/270/50/2,880/孩子0 → 总支出9,650，月现金流3,550；负债 190,000/150,000/19,000/9,000/1,000；储蓄400；每孩640。
- 经理（职业卡实拍）：工资4,600；支出 910/700/60/120/90/50/1,000 → 总支出2,930，月现金流1,670；负债 75,000/12,000/7,000/4,000/1,000；储蓄400；每孩240。
- P.12 示例：工资2,500 + 股利100 + 房产140+800 + 企业1,600 → 非工资收入2,640，总收入5,140；总支出2,490，月现金流2,650 → 2,640 > 2,490 达成进入快车道。

## 4. 开局（SETUP）

1. 每人选定职业（对应职业卡数据），系统生成初始报表（P.2 简明步骤 4–5）。
2. 初始约束：无银行贷款、无孩子（P.2 注意）。
3. 发钱：现金 = 月现金流 + 储蓄；随后储蓄清零（P.2 简明步骤 7、P.2 开始游戏 6）。储蓄不参与每月结算。
4. 线下掷骰定先后，房主录入顺序；顺序此后不变。
5. 每人选择梦想（快车道粉格）并记录（P.2 开始游戏 2）——系统需存 `dreamId`，供快车道加价规则用。

## 5. 老鼠赛跑：格子与行动

掷骰与移动在线下完成。系统不追踪格子位置，**由玩家在手机上声明本轮发生的事件**（停在什么格）。⚠️ADAPT：纸面"经过银行结算日忘了要求结算就作废"（P.3）不数字化——系统在结束回合时询问"本轮经过/停在银行结算日几次"，自动结算，不设惩罚。

| 格子 | 触发行为 | 引擎处理 |
|---|---|---|
| 银行结算日 | 停在或经过 | cash += 月现金流（为负则扣；现金不足以支付即按§8**强制进入破产清算**） |
| 机会 | 自选抽 小生意(≤$5,000) 或 大买卖(≥$6,000)（P.3） | 进入卡牌流程 §6 |
| 市场风云 | 抽卡 | 进入卡牌流程 §6.3 |
| 额外支出 | 抽卡，强制执行（P.3） | §6.4 |
| 慈善事业 | 可选：捐总收入×10%（现金付给银行） | cash −= round(总收入×0.1)；charity=3（此后3轮可选1或2粒骰）（P.4） |
| 孩子 | childCount+1（上限3，满3无效果） | 孩子支出重算（P.4） |
| 失业 | cash −= 总支出；skipTurns=2；charity清零（P.4） | 现金不足可贷款/破产检查 |

**机会卡通用规则（P.3）**：
- 资产只有在卡牌允许出售或破产清算时才能卖出；只能卖自己拥有的资产；不得多人合资。
- 抽卡人可放弃，也可把这次机会**转卖**给任意其他玩家，转让价双方线下议定后录入；买家必须立即按卡面价格购入该资产。
- 机会有效期：⚠️ADAPT 纸面为"下一个玩家前进时失效"，数字化为"抽卡人结束回合时失效"，效果等价且可判定。

## 6. 卡牌效果引擎

卡牌效果建模为**结构化效果指令（Effect DSL）**存于卡库（详见 design/04 §3），引擎逐条执行。以下为各类语义。

### 6.1 机会卡：房地产（小生意/大买卖通用）
字段：成本、首期支付、抵押贷款、月现金流、参考收益率、参考售价区间。
- 买入：cash −= 首期支付（不足可银行贷款补差）；资产+{首期,总成本}；负债+房地产抵押{金额=抵押贷款}；收入+房地产行{月现金流}（P.8 购入房地产步骤）。
- 首付即全部现金支出，月供已含在卡面月现金流中（P.8 注意）。
- 卖出（仅当市场风云卡触发或破产）：收益 = 卖价 − 抵押贷款额，先抵消贷款再入现金；收益为负则向银行付差额；删除对应资产/负债/收入行（P.8 卖出房地产）。

### 6.2 机会卡：股票/基金
字段：代码、今日价格、价格区间、每股红利（通常0）。
- 抽卡人可按今日价格买入任意整数股（cash 足够或贷款）；**所有玩家**均可在本机会有效期内按今日价格卖出持仓（P.11 示例卡：只有抽卡人能买，人人能卖）→ 引擎向全员广播卖出窗口。
- **窗口有效期 = 抽卡人的整个回合**：抽卡人放弃购买（`CARD_PASSED`）只表示他自己不买，不关闭任何人的卖出窗口（含他本人的持仓）；窗口在 `TURN_ENDED` 清空 `active_card` 时才失效。故 `_stock_card` 不看 `resolved`。
- 买入：资产证券行 +{代码,股数,每股成本}；有红利的股票在收入·股利登记（P.9）。
- 卖出：销售额 = 股数×卖出价，入现金，删行/减仓（P.9）。
- 拆股/并股事件卡（如"每两股并一股"）：按比例调整全员该代码股数，不涉现金，事件期间不可交易（MYT4U 实拍卡）。

### 6.3 市场风云卡
三种子类型：
1. **求购报价**（如"求购两室一厅 $55,000/套"）：所有持有匹配资产的玩家获得"卖出"选项，按 §6.1 卖出结算。选择权在各玩家。
2. **溢价收购**（如"有限合伙公司按原价3倍出售"）：同上，卖价 = 原成本×倍数。
3. **经济事件**：
   - 强制型（如"通胀爆发：持有的三室两厅出租房全部交给银行"）：强制删除匹配资产及其抵押负债、收入行，无补偿（按卡面）。
   - 修饰型（如"某类支出上调"）：按卡面调整对应字段。
- ⚠️ 匹配规则：卡库中每张市场卡带 `targetAssetType`（如 "2室1厅"、"3室2厅"、"有限合伙"、"8室公寓"），资产也带类型标签，引擎按标签自动找出受影响玩家。

### 6.4 额外支出卡
强制执行（P.3）。三种子类型：
1. 纯现金：cash −= 金额；带条件的（如"有孩子才付"）按条件判定。
2. 可选信用卡支付（如彩电 $4,000）：玩家二选一——现金支付；或 信用卡负债 += 金额 且 信用卡支出 += 卡面月供（如 $120）。
3. 分期负债型（如游艇：首付 $1,000 + 负债 $17,000 + 月供 $340）：cash −= 首付；新增负债行；新增周期支出行。
- 现金不足：必须银行贷款补足（P.3）。

### 6.5 玩家间交易（通用过账原语）
`transfer(from, to, amount, reason)`：A 发起 → B 确认 → 过账。用于机会卡转卖费、其他线下议定的合规交易。资产过户仅发生在"机会卡转卖"场景：费用走 transfer，资产按卡面价格由买家对银行结算（§5 机会卡通用规则）。

## 7. 银行操作

- **贷款**（任意时刻，除非已破产，P.4）：金额 = N×$1,000；负债·银行贷款 += 金额；支出·银行贷款支出 = 余额×10%；现金 += 金额。说明书没有额度上限，也不因"贷后现金流为负"而拒绝——但**宣告破产后不得再贷款**（`IN_BANKRUPTCY`），破产不是可以靠续贷绕开的。
- **还款**：按 N×$1,000 偿还，利息支出同步 −N×$100（P.5）。
- **清偿其他债务**（每轮可选，P.4）：除银行贷款外必须**一次性全额**清偿单项负债；清偿后删除对应负债与支出行，重算。税金、其他支出、孩子支出为长期支出**不可清偿**。

## 8. 破产（P.5、P.11）

触发：银行结算日月现金流为负，且现金不足以支付。**这是判定，不是选项**——原文「那么您就破产了」。
`PAYDAY` 一旦算出付不出到期款项，引擎直接产出 `PAYDAY_UNPAYABLE` + `BANKRUPTCY_STARTED` 把玩家推进清算，
不给"先去贷款"的出口（否则可以靠无限续贷把负现金流永远拖下去）。一并结算多个月时**逐月**判：
付得起的月份照常结算，第一个付不出的月份触发破产；`PAYDAY_UNPAYABLE` 只是审计事件，不动账，
付不出的这个月不结算、事后也不补缴。清算流程（引擎引导逐步执行）：
1. 玩家所有资产以**首期付款的 50%** 卖给银行（逐项结算，对应负债注销）；
2. 所得偿付债务，直至月现金流转正；
3. 若转正：skipTurns = 3，继续游戏；
4. 若卖光资产仍为负：注销 购车贷款、信用卡、额外负债 各 50% 及对应支出的 50%；住房抵押与教育贷款保留；
5. 若仍为负：玩家出局（OUT），资产由银行回收，对局继续。

## 9. 进入快车道（P.5）

条件满足（非工资收入 > 总支出）后，在**任意一轮自己回合开始时**可宣告进入：
1. 财产 = 老鼠赛跑阶段非工资收入，**以千元为单位四舍五入**，×100 → 初始"现金流量日收入"。
   - 例：非工资收入 $2,640 → $3,000×100 = $300,000？⚠️ 说明书原文为"以千元为单位，四舍五入"（记录卡背面）——2,640 应四舍五入到 3,000 再 ×100。**需按此实现并在测试中固定**（2,640→300,000；2,400→200,000）。
2. 胜利目标收入 = 初始现金流量日收入 + $50,000。
3. 老鼠赛跑的记录卡、三类卡牌停用；手头现金按说明书交回银行（✅已确认按说明书执行，不做设置项）。
   - **记录卡翻面后不可再清偿老鼠赛跑的负债**：`PAY_OFF_DEBT` 设阶段闸门，非 `RAT_RACE` 一律拒绝。
   - 老鼠赛跑的慈善剩余轮数一并清零（快车道慈善是另一套、且为永久）。
4. **进入即发放一笔等于初始现金流量日收入的启动资金**（P.5「将获得 100 倍的非工资收入（即您的财产），
   也就是您在『快车道』初始时的『现金流量日』收入」——✅ 房主已定案为进入即到账）。
   此后每次停在或经过"现金流量日"再领同样金额。
   > 净效果：交回银行的是老鼠赛跑攒下的现金，换来的是一笔与财产挂钩的启动资金，
   > 两者互不相干 —— 老鼠赛跑剩多少钱不影响进场金额。
5. 老鼠移至外环"在此进入"箭头（线下），此后每次掷 2 粒骰子（慈善后可选 1/2/3 粒）。
6. `ENTERED_FASTTRACK` 事件 payload 带 `passive_income`（换算前原值）、`initial_income`、
   `cash_returned`，供前端渲染换算过场。

## 10. 快车道：格子与行动（P.6）

| 格子 | 效果 |
|---|---|
| 月现金流量日 | 停在或经过：+现金流量日收入（可补领，系统自动化） |
| 企业投资（绿格） | 停在可买：付首期付款（快车道现金）；独占——一旦有人买，其他人不可再买；记录企业与月现金流增量，累计计入现金流量日收入；含掷骰条件的格子在成功前对停在此格的玩家保持开放 |
| 梦想（粉格） | 停在自己的梦想且现金足够 → 买下即胜利。停在**他人**的梦想可"双倍购买"：使该梦想成本 +原始成本×100%（可叠加多次），购买者放筹码但不拥有梦想；梦想主人此后须按累加后的价格购买（例：100,000 → 200,000 → 300,000）。停在**无人认领**的梦想：可按原价买下占位（`FT_CLAIM_DREAM`），不获胜、不加价、无其他效果——P.6"当您停在一个梦想格时，如果您有足够多的现金，您就可以选择将其买下"是通用表述，未限定必须有主，房主据此定案；因为没有玩家把它当目标，买下既不触发胜利（胜利绑定"您自己的"梦想，见 P.1、§11）也拖慢不了任何人 |
| 慈善 | 可选：捐 $100,000（棋盘格面，见 design/05 §3.2），其后每轮可选 1、2 或 3 粒骰子 |
| 税务审计 | 现金 ×50% |
| 离婚 | 现金 = 0 |
| 官司 | 现金 ×50% |

**快车道无银行贷款**（P.5）。现金不足不能买。

## 11. 胜利判定（P.3、记录卡背面）

1. 任一玩家买到**自己的梦想** → 立即获胜，游戏结束；或
2. 第一个使现金流量日收入较初始值**增加 ≥ $50,000**（通过购买绿格企业累计）→ 获胜。

## 12. 引擎裁决与校验规则汇总

- 所有金额为非负整数美元；股数为正整数。
- 任何扣款前校验现金充足；不足时给出"贷款补差"或"取消操作"选项（额外支出卡只能贷款）。
- 贷款/还款必须是 $1,000 整数倍。
- 孩子数上限 3；charity 轮数上限 3（老鼠赛跑）；skipTurns 期间仅允许查看与被动结算，不允许主动操作（清偿、买卖）。⚠️ 失业"停赛两轮"期间纸面无明确禁止清偿，按"停赛=跳过整个回合"从严处理。
- 每个行动生成不可变日志事件（见架构文档 §6），支持房主撤销→重放。
- 状态重算是纯函数：`state = reduce(initialState, events)`，禁止在事件之外修改状态。

## 13. 测试要求

1. **公式回归**：§3.2 三组说明书数值必须逐项吻合。
2. **流程用例**（最少集）：买房→市场卡卖房；买股→广播卖出→并股；游艇卡分期；慈善3轮倒计时；失业停2轮+慈善清除；贷款→部分还款利息递减；清偿购车贷款；破产三种出口（复活/减债复活/出局）；进入快车道换算（2,640→300,000 边界、2,400→200,000、2,500→300,000 四舍五入边界）；梦想双倍加价叠加两次；+50,000 胜利与买梦胜利；无人认领的梦想按原价买下占位且不获胜/不加价、对已有主的梦想拒绝该操作。
3. **属性测试**：任意事件序列重放后，总支出/月现金流等派生值与逐步计算一致；现金永不为负（除破产流程中间态）。
